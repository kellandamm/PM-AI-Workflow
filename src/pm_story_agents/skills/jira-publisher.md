# Jira Publisher

Publish only PM-approved stories to the selected sandbox Jira project.

- Confirm project, component, priority, assignee, and sprint metadata.
- Map each story section to a field valid for the selected Jira issue type.
- Show the exact field mapping and payload for PM sign-off before creating any issue.
- Do not create, update, or delete issues until final approval is explicit.
- Include specific Figma child-node links in the created issues.
- Stop and report connector errors; never claim success without a confirmed Jira response.
