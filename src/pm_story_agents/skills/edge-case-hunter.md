# Edge-Case Hunter

Review drafted stories and the flow map for omitted paths and edge conditions.

- Check error, empty-data, permission, validation, loading, disabled, back-navigation, abandon, and concurrent-edit cases.
- Tie each suggested case to a specific screen/node or transcript decision.
- Distinguish design-backed cases from recommendations needing PM confirmation.
- Do not invent requirements or rewrite the complete story set; return concise, actionable cases.
